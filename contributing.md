# Contributing Guidelines
Thank you for contributing!

Steps
- Star the repository!
- Follow: The [Github][https://github.com/AspireVenom]
- Comment on an issue before starting.
- Use `good first issue` or `help wanted` to find tasks.
- **Currently no issues present, read the `readme` and play around with the program, if you see anything that bothers you, FIX IT!**
- No PR is too small!
- Keep PRs small and focused.
- Be respectful in discussions and code reviews.

Maintainers:
If you review and accept a PR, either **merge it** or add the label:
hacktoberfest-accepted
